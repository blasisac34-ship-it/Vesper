# Vesper 1.8 — Global live radio

## Added
- New Radio page in desktop navigation, mobile navigation, and More menu.
- Popular live stations and top-voted stations.
- Search across the Radio Browser directory, with country, language, and genre filters.
- Paginated directory results and station metadata (country, language, codec, bitrate, website).
- Radio playback uses Vesper’s existing audio engine and player controls.
- Server-side caching for directory results; no YouTube API or YouTube lookups are used for radio.

## Notes
- The directory is community-maintained and aims for broad global coverage; no catalog can promise literally every station.
- Individual station streams can be offline, geoblocked, HTTP-only, or incompatible. Vesper does not control those streams.
- Existing accounts, saved music, playlists, settings, and YouTube matching behavior are unchanged.
